## Notes

The diagnostic-response side of the `0x750` gateway. See `0x750.md` for the gateway architecture and the mixed-addressing frame format. **Always strip the first byte (address-extension / sub-target) before applying standard ISO-TP rules.**

Negative responses (`0x7F`) were observed only as standard "no DTC at that record" / "sub-function not supported" patterns during Health Check fan-outs. Nothing pathological.

**ISO-TP flow control:** the gateway sends `30 00 01` (continue, no block size limit, 1 ms STmin) — same as other Solterra ECUs. The 1-byte address-extension overhead does NOT change the flow-control format; only the payload framing.
